# Royal Housing BD — redesign prototype

Static site, no build step. Deploy this folder as-is.

**GitHub Pages:** push these files to the root of a repo → Settings → Pages → Deploy from branch (main, / root).
**Netlify / Vercel / Cloudflare Pages:** drag-and-drop this folder, or connect the repo with no build command and `/` as the output folder.

Pages (hash routes): `#home`, `#projects`, `#listings-plot` (also property, flat, resort, hotel), `#p-plot` (also property, flat, resort, hotel), `#masterplan`, `#gallery`, `#about`, `#consult`.
